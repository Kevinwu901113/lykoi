## 结果

新增无第三方运行时依赖的 `lykoi-composer` 包与独立 `profile/composer.ts` 入口。WebUI 可完成组件选择、配置、连接、定义版本保存、实例创建、运行、人工等待续接和结果观察。默认示例为明确标识的离线演示模型；另提供 OpenAI 兼容模型适配接口和部署凭证句柄。

Agent 是整个装配系统；Core 只做一次模型计算，循环由可选执行策略承载。定义和运行状态分离：修改产生新版本，新运行使用新版本，已有运行固定创建时快照。多个 Core 只有显式绑定同一实例资源才共享资源，跨实例工作区和资源对象独立。

操作先记录意图再执行；真实回执持久保存。人工等待回执与继续运行在同一事务中提交，重复回调幂等、冲突回调拒绝。暂停、取消、活动时长与全运行工具步数上限均有测试。进程中断或未确定的外部结果进入 unknown，等待核验，不自动重做。部署入口有单进程锁；强杀后的锁需要核验旧进程已停止后再清理。

## 使用与剩余范围

使用说明：`docs/composer.md`。仓库根目录执行 `npm ci`、`npm run composer`，打开 `http://127.0.0.1:4310`。

这是首条垂直链路，不是完整 Dify 替代品。条件分支、汇合、拖动布局、流式/多模态模型协议、费用预算、事件 Inbox、自动外部结果核验、插件文件安装、执行沙箱以及可选人格/记忆/心跳仍未实现。首版仅支持可信预注册组件、本机单进程部署和六种预置组件。

后续优先完成真实浏览器复核，再围绕首个完整业务场景扩展组件与调试粒度；不把旧人格体系重新放回新版底座。
