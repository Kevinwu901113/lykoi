# STATE-CONTRACT 增补件 016（2026-09-01，随 WO-MEM-SOURCE-01 复核落档）

对 WO-M0-STATE-CONTRACT report §1.2 `experiences` 的增补。原存档件不改
（历史不改写）；本件为现行契约的一部分，与原 §1.2 合读。

## experiences 新列（mind_schema 16 起）

```sql
epistemic TEXT CHECK (epistemic IS NULL OR epistemic IN
    ('observed','executed','user_reported','inferred','imagined','simulated'))
```

- 认识论第二轴，与渠道轴 `source`（八值 CHECK，不变）正交。
- `NULL` 含义唯一：016 回填之前写下且未被回填的旧行。读侧一律
  NULL-安全（`IS NULL OR NOT IN` 全句，SQL 三值逻辑）。
- append-only 触发器 `experiences_immutable_columns` **不列** `epistemic`
  ——本列可后补（回填合法），其余列不可变约束原样。

## 写入方默认推导映射（正本：persona_layering_design_v1 §3.1）

| source | epistemic 默认 |
|---|---|
| wake_action / action_result | executed |
| owner_event | user_reported |
| silence / environment / system | observed |
| thought_lapse | inferred |
| conversation（对方产出/缺方向） | user_reported |
| conversation（她自己产出，显式 outbound） | executed |

推导永不产出 `imagined|simulated`——虚构地位只能由写入方显式声明。

## 铁律（读侧）

`imagined|simulated` 不进任何事实性供给通道（快照 recentExperiences、
整合 INTAKE、L3 检索）；测试钉死（rw-epistemic.test.ts 用例 6）。
