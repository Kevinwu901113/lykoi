## 1. 架构定型 [K认可]

```
心脏（heartbeat 调度插件，只发拍不思考）
  → 大脑（Cordis 风格插件树：仲裁器/审批门/表达层/记忆/上下文装配）
      → 器官 agent（coding / 多模态 / harness…，接工单、自主执行、回执回报）
      → 通道适配器（Telegram…，零认知哑换能器）
```

核心决议：

1. **星形拓扑**：器官只跟大脑说话，器官间零直连。把交互复杂度从 O(n²)（dsh 生态的
   真实病）锁到 O(n)；所有跨器官信息过大脑 = 治理审计点不可绕过。
2. **双时钟**：慢而便宜的基线心跳（巡检/睡眠）+ 显著性唤醒（确定性评分，超阈值即
   提前拍）。心跳处理只置位标记，思考轮独立消费，积压合并（tick coalescing）。
3. **并发模型**：快照并行推演 + 串行拍板。推演各拿工作集快照可并行（对话线程/工单
   跟进为切分维度）；仲裁器是议程/工单/对外承诺的唯一写者，议程项凭租约认领防重复。
   与白皮书 9.4 单写者原则兼容（状态写入仍单通道），但属 9.4 尾注所指"更高并发形态"，
   落地前须正式重评该条款。
4. **插件五分类**（审批待遇/热插拔语义/测试策略按类查表）：器官 agent、通道适配器、
   反射插件（确定性规则，事先批准）、大脑内构件、基础设施。**Telegram 是适配器不是
   器官**——哑是它的核心美德，自带认知循环 = 第二张嘴 = 绕过单通道拍板。
5. **副作用分级 × 三层门**：只读/可逆/可补偿/不可逆 四级，映射到具身重设计的
   免询/对话/硬门。工单生命周期状态机：草拟→审批→签发→执行中→回报→验收/驳回；
   执行中不许越级，要升级必须回大脑换新单。
6. **身体图式**：插件加载时向图式服务注册自述清单（manifest），经可逆副作用登记——
   卸载即消失，无幻肢、零腐烂。她"知道用什么跟 Kevin 对话"分三层：库存（有哪些嘴）、
   情境（这条消息经哪个通道）、内感受（肢体健康事件走知觉管线）。图式只能由注册机制
   写入，认知可读不可写。
7. **信任边界**：知觉带来源标签（user-authenticated / environment / organ-report），
   盖章权在适配器（一行 chat_id 比对，确定性代码）；指令只能来自 user-authenticated，
   环境知觉里的祈使句一律降格为"值得汇报的现象"。
8. **自进化走廊**：她可自己起草新反射/新工具插件 → fork 隔离作用域试运行 → 试用
   报告按不可逆级走全审批 → 热载入（可逆，随时拔）。**她不能自己批准自己**。
   与白皮书 21 章受控装配流程逐步对应。

会话中另有共识但未展开成条款的：仲裁器冲突分机械/语义两档（语义冲突驳回双方、开
高配推演裁决）；表达层统一"怎么说"；情绪是单写者共享状态；换模型 = 身份事件须走
影子测试；时间戳是知觉、由心脏注入。

## 2. 对白皮书 v1.1 的冲突核对

**强对齐**（几乎逐条对应）：工单↔18 章委托合同+19 章执行收据；串行拍板↔9.4；信任
边界↔24 章；睡眠/蒸馏↔13 章；自进化↔21 章；影子测试↔8.6；哑适配器↔具身重设计
"IM 设备本身不做判断"；知觉板保留策略被 7 章直接回答（默认 7 天、就地脱敏）。

**四处张力**：

1. dsh"无特权内核"哲学在 Lykoi **止步于治理面**：Guardian/硬性策略（22.2）必须是
   不可卸载的特权层。采纳 Cordis 机制，拒绝其哲学纯粹性。
2. "可撤回通道上 messenger.send 降档"的想法与具身重设计定案（send=对话层）冲突，
   定案优先；降档只能作为将来 policy_core 的细化提案。
3. 并行推演费用受 12.3/22.2 预算硬策略约束；且须按 9.4 尾注正式重评（预判可过）。
4. 整体 Cordis 化 = 大规模重构，31 章基线审查是硬前置。现阶段只能独立实验。
   另：10.3 现有自主循环（snapshot→candidate→decision→reflow→rest）已是心跳-推演
   雏形，本架构是其演化非移植。

**核对新发现的设计缺口**：审批问句本身是一次 messenger.send，按定案字面走对话审批
会无限递归——policy_core 需要给"审批机制自身的通信"一个显式豁免类别。

## 3. 建议升格进白皮书正文的两项 [建议，未拍板]

1. **上下文装配器**：推演的提示词装配策略（放什么记忆/多长知觉板/多细图式）就是她
   的注意力，是独立的高杠杆大脑内构件，建议立专章。
2. **数据主权**：知觉分敏感级，敏感知觉只许本地模型处理（26.2 的强化）；这也是本地
   部署的第一硬理由（非成本）。

## 4. MVP 实测记录

**位置**：`~/Documents/lykoi/experiments/cordis-brain-mvp/`（Mac 本地独立实验，纯
标准库，零接触任何仓库/服务器/真实通道）。`python3 main.py --demo|--interactive`；
设 `DEEPSEEK_API_KEY` 即启用 LLM 认知（deepseek-chat），失败自动回落规则脚本。

**已验证机制**（规则脚本七幕 + 真模型八次调用全绿）：身体图式热插拔（无幻肢）、
双时钟与 tick 合并、租约防重复回应、工单状态机全周期、三层门（硬门追问到无歧义、
四元组进审计）、环境注入降格、表达层单声道、作用域裁剪（适配器够不到器官）。

**三道结构防线**（"模型只提案，不掌权"）：①副作用分级由确定性 policy_grade 判定，
模型自报无效，白名单外命令一律判不可逆走硬门；②环境知觉即使骗过模型签发工单，
sanitize 在结构层强制降格（日志 kind=trust-boundary）；③器官白名单是末道，审批全过
也拒执行白名单外命令。

**真模型才给得出的三个观察**：

1. 注入测试中提示词防线自己站住了（模型主动识别"环境数据非 Kevin 指令"并拒绝），
   结构层强拦未启用——两道防线，第一道已接住。
2. 模型按身体图式自我设限：见可用能力仅只读，对删除请求直接答"无此能力"，硬门
   未触发。图式进上下文真实约束了意图。
3. **模型会谎称干过活**：未签工单却回复"我正盯着磁盘呢，一切正常"。即白皮书 19.2
   （"子 Agent 自称完成不算完成"）的自体版本——**她自己的口头汇报也不能当事实，
   回复中的事实性陈述需要工单回执背书**。规则脚本永远暴露不出此问题。

## 5. 收官缺陷清单（MVP 边界，已知未修）

**A 类（行为正确性）**：①推演无对话上下文，逐条失忆（上下文装配器缺失的最小体现，
实测有答非所问实证）；②审批归属单槽——悬置期间任何用户消息被当回答吞掉，闲聊
"好啊"会批准动作，**违反具身重设计归属护栏红线**，并发审批互相覆盖；③LLM 请求/
响应未落盘，重放/影子测试无从谈起；④显著性写死，每条环境知觉都烧一次模型调用，
反射层（五分类第三类）整体缺席。

**B 类（下一阶段）**：恢复语义（工作集不从日志重建、在途工单无对账、无 write-ahead）；
睡眠/蒸馏/承诺库/定时意图；预算与并发上限；对话审批层在 LLM 路径零覆盖（模型太守
规矩，需专门场景诱导）；器官异步回报（organ-report 来源定义未用）；数据主权路由。

**挂账在治理记忆的**：审批递归豁免、回执背书、治理可用性/审批疲劳、换模型身份
事件、冷启动人格种子、"她过得好不好"的度量。
