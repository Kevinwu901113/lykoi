## 0. 现状基线（2026-08-09 实勘，修正 7 月记忆）

双端管线比记载的深：Mac watcher 9 种事件（7 种 Level-A 元数据已上行 +
screen_ocr / audio_utterance 本地实现、被协定 v0.2 挡在上行外）；服务器
`/ingest/environment` 严格 schema（内容类字段 fail closed）+ 幂等去重 + 限流，
事件进 `environment_core_event_outbox` 喂 M3 注意力管线——**core 已在听，缺的是
感官纵深上行与"感知→记忆"提炼**。

## 1. 为什么感知（目的排序）

1. **共享语境**——陪伴的实质："你今天在干什么"成为共同知识而非转述。
2. **主动性时机**——打扰成本模型（白皮书 12.2）的输入；无感知的主动是闹钟，有感知的是室友。
3. **关怀的物质基础**——作息/连续工作时长/节律异常。
4. 执行辅助（次要）。

**反目标**：不是监控软件、不是 quantified-self。判据：凡"数据有趣但她用不上"的不采。
情绪代理信号（打字节奏等）不采。

## 2. 感知什么（四层信号模型）

| 层 | 信号 | 服务于 | 敏感度 | 决定 |
|---|---|---|---|---|
| A 在场可交互 | 在/离/锁/idle | 时机 | 低 | 已上行，维持 |
| B 活动语境 | app+粗化标题 | 状态级语境 | 中 | 已上行，维持 |
| C 节律负荷 | 工时/休息/作息 | 关怀 | 中 | **服务器端由 A/B 推导，Mac 零新采集** |
| D 内容纵深 | 屏幕/语音内容 | 深语境 | 高 | **屏幕：就地提炼后上结论；语音：搁置** |

## 3. 定案（2026-08-09）

1. **D 层走就地提炼**：OCR 原文不出设备。Mac 端规则聚合器把 OCR 窗口聚成
   `activity_summary`（时间窗+主题+置信度），原文本地短存即焚。成本核算：聚合
   本身近零（毫秒级字符串处理），成本大头在 OCR 采样——配套采样纪律
   （focus 驻留 >N 秒才采 + 变化检测去重），预期还能压低 watcher 现有 CPU 尖峰。
   本地小模型不做，规则法天花板碰到再议。
2. **音频相关一概不做**（Kevin 2026-08-09 二次修正，覆盖此前"默认关"方案）：代码、
   配置、默认值全部维持现状不碰，语音提炼不做——**整条音频路线等想明白后另行设计**，
   本设计不定案、不派生任何工单项。
3. **presence 状态机放 core 的 M3 管线内**（主治理 Agent 定）：available /
   focused / meeting / away / dnd，纯规则毫秒级推导，不过 LLM，输出作为
   autonomy 打扰门输入。
4. 隐私滤网升级为分层策略：密码类 app 黑名单 → 标题粗化 → 内容不出端；
   补浏览器隐私窗口与金融类目。
5. 信任边界顺路修：percept 专用 token（独立 Keychain 条目）+ 仅端口转发的
   受限 ssh key（用户端不再持有 lykoi 账户全权限钥匙）。

## 4. 服务器侧三条消费路径（core 拿到之后）

- **实时**：ingest → core outbox → M3 注意力 + **presence 状态机**（新增）。
- **巩固**：percept_buffer（7 天）→ 离线巩固/做梦周期提炼 → private 记忆
  （source=perception+时间范围，memory_scopes: user_001 / sensitivity=content）。
- **遗忘**：7 天 TTL 机械删除，结论保留；原始流永不进模型上下文
  （提炼任务最小窗口除外）。

协定 v0.3：ingest 增收 `activity_summary` 事件类（服务器仍拒收任何原文类字段）。

## 5. 实施切分

- **Mac lane（可立即并行）**：WO-MAC-PERC-03 —— 聚合器 + 采样纪律 + 音频默认关
  + 滤网分层 + activity_summary 本地落队列（上行开关默认关，等服务器 v0.3）。
- **服务器 lane（排六目录锁队列）**：协定 v0.3 + percept_buffer 三路径 +
  presence 状态机（在 P2-05 内，序于 P2-01 之后）。
- 音频：显式搁置，无工单。
