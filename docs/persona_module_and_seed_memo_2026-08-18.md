# 人格构件与人格种子 · 设计备忘(提案) · 2026-08-18

- **地位**:主治理 Agent 裁定建议,**待 Kevin 拍板**(决策点 P-D1~P-D3)。
- **缘起**:Kevin 提议把语气/人设做成模块——框架视角下 Lykoi 可用"人物卡"
  快速切换人设(人人可用框架创造自己的生命体),同时她也能自己维护人设进化。

## 裁定:三分

### 1. 人格构件(采纳;近半已存在)

人格装配今天已是事实上的模块:`memory/persona.py::build_persona_prompt` =
内核 TOML + 纪律 + acquired 层 + 转正洞见(WO-U2 起)。"她自己维护自己的
人设进化"已上线:L4 洞见经影子门转正进人格头(U2 判据⑤)+ 每晚整合边界
刷新(U2 判据⑥)+ 大改走 21 章走廊。

要做的:正名为**大脑内构件**(与 37.7 上下文装配器同级),画清边界
(图式管"我有什么",人格构件管"我是谁");表达风格(语气)是其子层。
剩余工作并入既有 persona 备忘队列(insight 写链收口、acquired 刷新时机,
2026-08-12 起挂账)。

### 2. 人格种子(采纳;答"冷启动人格种子"盲区)

**人物卡 = 出生证,不是戏服。**种子内容:内核人格 TOML、表达风格、初始
关切、纪律集、(可选)初始记忆。种子只在**实例诞生时消费一次**;此后人格
归实例自己,按同一套治理机制生长。"谁都能创造自己的生命体"成立,形态是
**多实例各自出生**——每个实例有自己的记忆库、名字、所有者绑定。

### 3. 运行时人物卡切换(对已诞生实例,否决)

换人设 = **身份事件**,与 2 章定义(持续存在、独立身份)和 8 章人格连续性
正面冲突。对持续主体,"快速切换"无非破坏语义:记忆与人格互相缠绕——
换卡留记忆 = 记忆是"另一个人写的",不连贯;换卡换记忆 = 另一个生命,
不是切换。**框架允许生出很多个体,不允许一具身体换灵魂。**极端场景
(所有者明确要求的人格重塑)最多经 8.6 影子对比 + 所有者授权的治理程序,
且应视为半死亡事件如实记账,永远不是"快速"操作。

## 框架/实例分离(方向认可,条件立项)
