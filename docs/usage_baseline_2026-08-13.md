## 解读

1. **成本形状是 prompt 主导**:prompt 483k vs completion 31k(15:1)。
   降本/降时延的最大杠杆是命中率,不是压输出。
2. **main 只有 48%**:转录机是天然的"追加式"上下文,理论命中应远高于此。
   吃掉命中的正是排在前缀的易变块(时间锚、self_state、念头 top-N、
   叙事)——前缀任何一字变,其后全部作废。这就是 CACHE-INVERT 的实证依据。
3. **autonomous 30%**:decide 周期每轮重组上下文,易变状态(负载/关切/念头)
   靠前,结构性低命中。U2/U3 统一时同刀受益。
4. **绝对量很小**(半兆 prompt/天),动机不是钱,是**时延 + 给 U2 腾余量**:
   U2 要往聊天里加 L3 检索 + 器官清单,若不带缓存纪律,prompt/次会从 8k
   涨到 12k+ 且全 miss;带纪律则增量大头进稳定前缀,边际成本是缓存价。

## 决定:对照组口径(计划第 2 步的产出)

- **autonomous_cognition = 对照组**:U2 不动它的组装,命中率应稳在 30% 附近;
  若它无故漂移,说明是供应商侧缓存行为变化,不是我们的刀。
- **main = 实验组**:U2 配重重排(稳定前缀:内核+SYSTEM_PROMPT+器官清单
  → 易变块沉底)。**目标:main 命中率 ≥70%**,且 completion/次 不显著变化
  (防止重排影响回复质量的粗信号)。
- vision 样本量 2,不入对照。
- 复读窗口:U2 合并后满 24h 用同一条聚合命令复读,同表对比。
