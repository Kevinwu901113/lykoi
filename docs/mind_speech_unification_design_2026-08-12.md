## 1. 目标图景(一句话)

**只有一个主体。**你的消息是她的一次感知;她的回复是她心智周期**选择**的
一个动作(与自主路径同一套 dispatch:回执/预算/审计);她的记忆参与每一轮
(L3 检索,不是转录回放);她说过什么、有没有送到,都是她能感知的事实。

## 2. 核心统一:对话轮 = decide 周期的对话情境形态

现有 `mind/decide.py` 已经是"一次调用 → 状态+候选+成本 → 动作决定"的机器。
统一不是给对话新造一台心智,而是**让对话成为 decide 的一种情境**:

```
消息到达 → 落经验(immediate)+ 触发即时唤醒(不等 tick)
  → 周期上下文 = 人格内核 + 器官清单(静态,进缓存前缀)
              + 当前叙事 + 活跃关切 + 高荷念头
              + L3 检索(以来话为探针,跨时间调相关经验)
              + 短近对话窗(最近 N 轮,降级为一个输入而非主体)
  → 一次 LLM 调用,产出信封:{想:念头增删/荷变化, 说:动作(messenger.send
     文本 | 工具序列 | 沉默), 情绪脉冲}
  → 说走 dispatch → observation(送达回执/失败)→ 回落为她的经验
```

关键性质:
- **一轮一调用保持不变**(想和说在同一个信封里,不是两次调用)——时延与成本
  与今天同量级;
- **沉默是一个动作**(她选择不回,有账);**送达失败是一次感知**(她知道话
  没出去,下轮自然重说——"人呢"冤案在结构上不可能再发生);
- inner 通道消亡:想不再是回复末尾的选做附言,是信封本体;
- 工具循环保留但有界:对话情境允许一个周期内的短工具序列(截图→看图→回答),
  超界走 promise_followup 的后继(它改名为"周期接力",不再是 bolt-on)。

  动作出站;回执/失败落账并回灌经验。conversation.py 暂存,但其输出已是
  动作而非返回值。(统一的第一块承重墙;洞 A 结构性关闭。)
- **U2 · 心智入场**:对话上下文接入 L3 检索 + 活跃关切 + 器官清单(D5 定界,

## 5. 不变量(重构全程不许破)

1. 审批/建议两台问答机(S3/L5)在 kernel 层按 reply_to 先行拦截——不动;
2. 红线全套:空整合不伪造、释放权限语义、approval_rules 永无写路径;
3. 她的失败方向永远朝安全侧:周期失败=沉默+落账,不是乱说;
4. 影子期内旧路径为准,新路径只记不发(D4);
5. 每期 manifest 重签 + 全邻接测试,老规矩。
