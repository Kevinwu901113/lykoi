## 2. 腿一 · 收编进 U 线（不改已拍板范围，只补政策附文与判据）

U3/U4 范围 Kevin 已拍板（D1–D5），不注水。Cordis 核对暴露的两个缺口恰好是 U3 的
前置与判据，按最小侵入落法：

- **P1 · 审批递归豁免（U3 硬前置政策附文）**。今天不递归是因为审批问句由 S 线
  问答机在结构上发出（kernel 层 reply_to 拦截），事实豁免、无政策条款。U3 周期
  合一后"说"全部并进 decide 信封，按具身重设计定案字面（messenger.send=对话层）
  会无限递归。落法：policy_core 提案短文，给"**审批机制自身的通信 + 在场对话应答**"
  显式豁免类别，随 U3 工单附投，并在 U3 判据里加一条"审批问句路径不经对话门"。
- **P2 · 回执背书（U3 判据 + 影子期对比项）**。MVP 实测模型会谎称干过活（未签
  工单却报"一切正常"）= 白皮书 19.2 的自体版。U3 信封里"说"的**动作性事实陈述必须
  可对到 dispatch 回执**；恰好 D4 影子双跑 3 天可以量化"无回执的事实性陈述"频次，
  作为切换门的一部分。v1 落提示词层约束 + 影子期审计探针；结构层校验器留 C 线。
- **P3 · 图式升级路径预留（记录性约束，U3/U4 零动作）**。U2 器官清单是代码派生；
  C 线注册式身体图式到来时应是**换实现不换语义**。约束：U3/U4 不得让清单生成与
  对话装配深耦合（保持纯函数出入口），否则将来切注册视图要返工。

## 3. 腿二 · C 线（Cordis 结构件，每段一门）

- **C-A · 认知核基线审查 + 9.4 重评**（31 章硬前置，C 线入口门）。
  范围：`mind/decide`、autonomous 循环、U3 后的对话情境路径、唤醒/调度现状、
  全部状态写通道清点、费用画像。产物：基线报告 + 重构资产清点 + **9.4 尾注并发
  重评附文**（并行推演+仲裁器租约形态的正式评估）。
  前置：**U3/U4 落地后再审**——审查对象是收官后的形态，审早了白审。
- **C-B · 心脏抽出**。显式 heartbeat 调度件：基线节律 + 显著性唤醒（调度侧）+
  tick 积压合并；由现有 autonomous 定时循环**演化**（10.3 已是雏形）。影子期对比
  唤醒次数/费用/时延。依赖 C-A。
- **C-C · 器官段**。第一个真器官 agent 经 Delegation Gateway 接入。Gateway 是
  **阶段 2 步 3 的既定冻结设计**（contracts/receipts 表 + `delegation.*` 资源 +
  T1 Runner + broker handle；broker 已上线，其余未做），不算 Cordis 新增——Cordis
  给了它第一个真实消费者。首个委托沿用 2026-08-09 决议：lykoi-ui 低风险小修。
  器官回执直接喂 P2 背书机制闭环。依赖：阶段 2 步 3（可与 C-A 并行推进）。
- **C-D · 插件树 / 热插拔 kernel**（远期，条件立项）。立项条件：**≥2 个真器官在役
  且插拔成为真实运维需求**。在此之前不做——防为架构而架构。无论何时，治理面
  （Guardian / 22.2 硬性策略）是不可卸载特权层，永不插件化。
