# Lykoi

面向有基础能力的技术开发者的可视化 Agent 装配框架。在 WebUI 中选择组件、配置资源和连线，组成可执行、可观察、可恢复的 Agent。

当前实现为 **Composer**。Core 负责一次模型计算，执行循环属于可选运行策略；人格、长期记忆、自主唤醒和聊天渠道不是默认依赖。

## 启动

需要 Node.js 24+。

```sh
npm ci
npm start
```

打开 `http://127.0.0.1:4310`。`npm run composer` 是同一入口的别名。部署配置可通过 `npm start -- /absolute/path/to/deployment.json` 显式传入；凭据文件放在仓库外。

点击“加载示例”体验基本流程，或点击“语义路由”体验决策、条件分支、人工审核和排他合流。示例中的演示模型和手动决策夹具均明确标注，不代表真实模型能力。

## 当前能力

- 12 个基础组件：开始/输入、提示词模板、模型 Core、决策计算、条件分支、互斥合流、数据转换、人工等待、输出、工作区读写、HTTP 请求。
- 可视化画布：节点配置和连线、拖动、平移缩放、撤销重做、布局保存和运行结果查看。
- 独立定义版本、实例工作区、持久操作回执与人工等待；中断时不盲目重放结果未知的外部调用。
- OpenAI 兼容生成接口、JEV 决策协议和同协议服务；模型可替换，执行策略由用户选择。

详细配置、恢复语义和限制见 [使用文档](docs/composer.md)。当前仅监听本机回环地址；尚无多人认证、通用代码沙箱、循环图或并行结果收集。

## 开发与验证

```sh
npm test
npm run typecheck
```

核心运行时无第三方依赖，使用 Node.js 内置 SQLite。DOM 和真实浏览器验收工具按文档在仓库外安装，不进入产品依赖。

```text
packages/lykoi-composer/    运行时、WebUI 和测试
profile/composer.ts        唯一启动入口
docs/                      当前使用与设计资料
governance/                历史决策、工单和验证证据
```
